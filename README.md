# Бинарное дерево
В данном проекте реализована структура данных бинарное дерево с всевозможными функциями для работы с ним:
- инициализация дерева
- создание отдельных узлов
- удаление отдельных узлов
- удаление поддеревьев
- привязка узла к родителю слева/справа
- dump отдельного узла в терминал
- графический dump всего дерева через dot
- читалка дерева из файла в формате preorder(тип данных %s)
- запись дерева в файл в формате preorder(тип данных %s)
- читалка дерева из файла в формате inorder/postorder(тип данных %d)
- запись дерева в файл в формате inorder/postorder(тип данных %d)
